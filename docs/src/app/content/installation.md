## System requirements

| Requirement | Details |
|-------------|---------|
| **Browser** | A current version of Chrome, Safari, Firefox, Edge, or another modern browser |
| **Account** | Free Themys account (sign up at [themys.ca](https://themys.ca)) |

## Use the web app

No installation is required. Visit [themys.ca](https://themys.ca), create an
account, and open [the scan page](https://themys.ca/scan/new).

1. Enter the public URL of a Terms of Service, Terms of Use, or Privacy Policy page.
2. Select **Scan Now**.
3. Review the attention level, flagged clauses, and structured extraction.

The web app is the current supported workflow and works in any modern browser.

## Chrome extension: coming soon

The Chrome extension is being prepared for release and is not available in the
Chrome Web Store yet. Do not install files from unofficial sources or use a
placeholder listing. We will update this page after the listing, permissions,
privacy disclosure, and authenticated end-to-end checks have been verified.

## Privacy

The web app retrieves only the public legal-document URL that you submit. See
the [Privacy Policy](https://docs.themys.ca/legal#privacy) for details.
