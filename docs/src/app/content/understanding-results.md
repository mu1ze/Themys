## Start with the Summary

The results page opens with a plain-English briefing. It shows the document type, scan date, attention level, finding counts, and up to three priority findings. Open a finding to read what it means, why it matters, what you can do, and the wording that supports it.

Use the navigation to move between **Summary**, **Flagged**, **Actionable Insights**, **Compliance**, **Extraction**, and **Full Document**. The navigation is a sidebar on wide screens and a compact bar on smaller screens. Each report section uses the same expandable finding layout; there is no separate slide-out inspector.

## Attention Level and Severity

The attention level tells you how much review the document deserves. A higher attention score means more review is needed. It is review guidance, not a legal risk determination.

| Attention level | Meaning |
|-----------------|---------|
| **Standard** | Lower review priority |
| **Worth reviewing** | Some clauses deserve a closer read |
| **Needs attention** | Review the flagged terms carefully before agreeing |

Individual findings use a simpler signal: **Warning**, **Noteworthy**, or **Informational**. A term can be common across providers and still be noteworthy. The label does not establish whether a clause is lawful, enforceable, or available for negotiation.

## What Each View Contains

### Flagged

All flagged clauses, ordered for review. Open a row for its explanation, suggested next step when available, and a quote from the analyzed text. Use **View in the original document** to open the **Full Document** view with the matching wording highlighted when it can be located.

### Actionable Insights

Concrete steps you can start now, such as using a documented account control, sending a data request, or asking the provider to change a term. Monitoring advice, preparation, and remedies that require a future event stay with their clauses instead of appearing here. An **Available action** is presented when the analyzed wording describes a procedure or right; a **Suggested ask** is a request you can make now. Open the row to inspect the supporting wording before relying on a deadline, setting, contact method, or legal right. You can copy the proposed action.

### Compliance

Regulatory framework scores and the clauses linked to each framework, when the scan has those connections. Open a framework to see article references and connected wording. A framework score is an automated signal, not a legal compliance opinion.

### Extraction

Structured sections and key points generated from the document, when available. Open a section to read its points and any quotes. Extraction is a summary of source material, not the full legal text. See [Extraction View](/extraction) for details.

### Full Document

The stored original text in a dedicated view. Use it to check the context around a finding or extraction point. If the original text is unavailable for a saved scan, this view says so rather than reconstructing it from generated summaries.

## A Practical Review Order

1. Read the **Summary** and its priority findings.
2. Open the **Flagged** findings that matter to you, starting with warnings.
3. Check any **Actionable Insights** against their quoted wording.
4. Use **Full Document** to read the surrounding text before acting.
5. Consult **Compliance** and **Extraction** for additional context when those sections contain data.

Automated analysis can miss terms or misread context. Themys is not legal advice. For a high-stakes agreement, consult a qualified lawyer.
